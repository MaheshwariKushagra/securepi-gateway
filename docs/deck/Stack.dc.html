Deliberately boring where it counts.

No build step, no SPA framework, no Docker — the small RAM budget ruled it out from day one. Every layer was chosen so a reviewer can inspect it.

HOST
Ubuntu Server 24.04 LTS · x86-64, 3.6 GiB
A laptop-class box: x86 packages, an SSD, and a built-in battery
NETWORK
hostapd · nftables · DNS-filter DHCP
Router, access point, NAT and firewall on one host
SENSING
IDS · DNS filter · mitmproxy 12
IDS flows & alerts, DNS decisions, selective TLS inspection
STORAGE
SQLite in WAL mode · one events table
No UNIONs in detection queries; readers never block the writer
DETECTION
Plain Python & windowed SQL — no framework
Every detection is a query anyone can run by hand to check it
CONSOLE
FastAPI · Jinja2 · vanilla JS · Chart.js 4
One hand-written stylesheet; Basic-Auth middleware, fail-closed
